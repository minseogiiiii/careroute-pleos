# 1.0.2 가정 배치 개발본 검증

승하차 위치·허용·보행·차량 비용·연결선은 개발용 가정입니다. 실제 Pleos SDK 호출과 실제 승하차 허용 확인 지점은 각각 0입니다.

- versionCode 102 / 1.0.2-demo / Android9 이상.
- Android SDK35 도구와 JDK17로 직접 release 빌드. 서명 및 ZIP 정렬 검사 통과. 기존 release 키와 동일한 서명 사용.
- 핵심 검사 45개 통과. 그중 한 검사는 기존 합성 모델의 2,048개 입력과 추천 결과를 비교합니다. 신규 9개 검사는 가정 허용 해제, 요청 차단, 저장·복원, 과거 시설 체크포인트 초기화 등을 포함합니다.
- Android9 API28 x86 에뮬레이터(1280×800, 160dpi, CPU 소프트웨어 실행)에서 정상 흐름 100개 확인과 프로세스 종료 후 복원 9개 확인을 통과했습니다. 포인터로 버튼을 누르고 3단계의 회전·복귀, 가정 해제 후 추천 보류를 확인했습니다. 스크롤은 프로그램으로 이동했습니다. 검사 수는 이용자 수가 아닙니다. normal.txt, restore.txt, verification.json을 참고하십시오. 이전 1.0.1 결과를 이번 결과로 전용하지 않았습니다.
- Gradle lintRelease는 이번 버전에서 실행하지 않았습니다.

새 추천과 수치가 실제 병원 현장·이용 적합성·고객 편익을 검증한 것은 아닙니다. 세부 가정은 ../ASSUMED_CAMPUS_KO.md를 확인하십시오.

최초 실행에서는 에뮬레이터의 System UI 응답 없음 창이 입력을 가로막아 중단되었습니다. 관찰된 System UI 대화상자의 Wait를 선택해 정리한 뒤 같은 APK로 재검사했습니다. 중단 기록은 initial-system-ui-interruption.txt에 보존합니다. 실차·다른 기종·확대 글꼴·실제 손가락 스와이프는 검증하지 않았습니다.

실행 캡처 17장은 captures/*-device.png에 있습니다. 정상 흐름 검사의 캡처는 실제 기기 화면이며 외부 시스템 UI를 포함합니다.
