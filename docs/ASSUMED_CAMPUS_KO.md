# 1.0.2 개발 시연: 시설 환경 참고, 승하차 배치 가정

서울대학교병원 연건캠퍼스의 주차 공사·복수 주차장·CMI 보행 제약을 참고했습니다. A/B/C/U의 위치, 승용차 이용 허용, 무단차 연결, 거리·차량 시간·주차장 연결은 개발용 가정입니다. 실제 시설 승인·현장 검증·실제 좌표·Pleos 연동은 없습니다.

## 가정한 배치

| 후보 | 역할 | 동승자 보행 가정 | 허용 상태 |
|---|---|---|---|
| A | 로비 앞 하차·픽업 비교 후보 | 편도 90m, 계단 포함 | 시연에서만 허용 가정 |
| B | 조건 충족 하차 후보 | 35m, 계단 없음 | 시연에서만 허용 가정 |
| C | 대체 하차 후보 | 55m, 계단 없음 | 시연에서만 허용 가정 |
| U | 나중의 별도 픽업 후보 | 35m, 계단 없음 | 시연에서만 허용 가정 |
| 전용구역 가정 | 더 가까워도 선택하지 않는 후보 | 10m | 모의 불허 |
| 미확인 가정 | 정보 미확인 후보 | 5m | 모의 미확인 |

좌표는 화면 배치용 픽셀입니다. 위 A의 계단 설정을 실제 본관 출입구의 계단 정보로 인용하면 안 됩니다. 2주차장·CMI는 실존 명칭을 참고하지만 연결선·시간·위치는 모두 가정입니다. 1Gate/2Gate나 실제 도로 주소를 하차점 좌표로 사용하지 않습니다.

## 재현할 핵심

기본 A/CMI/A: 동승자 보행 합계 180m, 방문 차량 합계 16분. 계단 회피+100m 적용 시 B/2주차장/U: 70m, 22분. 숫자는 이전 합성 비교값을 재사용한 설명용 입력이며 실제 절감 효과가 아닙니다. 차량 합계에는 나중의 픽업·귀가 계획도 들어가므로 실시간 ETA나 확정된 최적 경로가 아닙니다. 운전자 보행은 포함하지 않습니다.

B에서 하차한 뒤 2주차장을 재검색하거나 새 경로 요청을 만들지 않습니다. 주차 후 보관한 U로의 안내는 운전자가 직접 시작합니다. CMI로 운전자만 주차하는 대안도 동승자 계단 조건으로 일괄 제외하지 않습니다. 이 또한 가정 연결의 로직 확인입니다.

## 가정 해제

시연 도구의 ‘가정한 허용 조건으로 시연 · 실제 허가 아님’을 끄면 조건 충족 후보가 0개가 되고 최초 안내와 남은 주차 재요청·픽업 요청을 차단합니다. 해제 상태는 저장·복원됩니다. 기존 1.0.1의 저장 계획은 다른 장소 의미로 복원하지 않고 초기화합니다.

## 실제 조사 근거

- 주차 통제 공지: https://www.snuh.org/board/B051/view.do?bbs_no=7455&pageIndex=1
- 공식 주차·CMI 보행 안내: https://www.snuh.org/content/M002001003.do
- 통합 안내도: https://www.snuh.org/map.pdf

공개 안내로 확인한 사실은 본관 1주차장 공사, 복수 주차장, CMI의 안내된 보행 경로에 계단·언덕이 있다는 점입니다. 실제 승용차 승하차 허용 위치는 미확인입니다. 제휴·사용 허가·효과 검증을 주장하지 않습니다.
