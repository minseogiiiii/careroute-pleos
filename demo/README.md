# 현재 시연 영상 · APK 1.0.2

[90초 영상](CareRoute_FirstRound_Demo_90s_1.0.2.mp4) · [자막](1.0.2/CareRoute_FirstRound_Demo_90s_1.0.2.srt) · [원본 캡처·해시·검증](1.0.2/video-verification.json)

동승자 조건에 따라 하차와 연결 주차장을 함께 고르고, 나중 픽업까지 이어 쓰는 흐름을 보여줍니다. 앞 27초에 기본 A/CMI/A와 조건 적용 B/2주차장/U를 비교하고, 이어서 주차 안내 유지와 운전자 선택을 보여줍니다.

## 영상 형식과 확인 범위

- Android 9 에뮬레이터에서 실행한 APK 1.0.2의 실제 화면 캡처 10개 장면을 순서대로 편집했습니다. 연속 조작 녹화가 아닙니다. 앱 화면은 자르거나 내용 수정 없이 비율을 유지해 배치했고 옆에 설명을 추가했습니다.
- 90.000초, 1920×1080, H.264, 24fps, 2,160프레임, 음성 없음. 전체 영상 디코딩과 인코딩된 장면별 시각 확인을 수행했습니다. 재현한 동작 자체의 검사 기록은 [APK 검증](../docs/release-102/README.md)에 있습니다.
- 01:09부터는 정상 흐름과 별개인 프로세스 종료·복원 검사입니다. 해당 화면의 요청 #2는 운전자가 명시적으로 재개한 뒤의 값입니다. 정상 방문의 픽업 요청 #2와 같은 연속 세션이 아닙니다.
- 승하차 허용·좌표·연결·거리·차량 시간·신호는 가정입니다. 실제 SDK 호출 0회. 실제 병원 승인·실차·사용자 편익을 검증한 영상이 아닙니다.
- 보행 합계는 동승자의 하차→입구와 출구→픽업입니다. 차량 합계는 출발→하차→주차→나중 픽업→귀가의 합성 입력 합계로서 실시간 ETA가 아닙니다. 운전자 보행·주차 대기·요금은 제외합니다.
